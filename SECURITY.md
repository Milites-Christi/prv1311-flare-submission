# Security Policy

This repository is a submission for the Flare Summer Signal hackathon and
handles live mainnet transactions and decision-logic for an autonomous
trading system. Vulnerability reports are welcome and taken seriously.

## Reporting a Vulnerability

Do not open a public GitHub issue for a security concern.

Report privately using GitHub's private vulnerability reporting:
1. Go to the **Security** tab of this repository
2. Click **Report a vulnerability**
3. Describe the issue — GitHub will notify the maintainers directly and
   privately; nothing you submit is visible publicly

Reports are reviewed and you'll get a response acknowledging receipt.
We don't publish details of confirmed or resolved vulnerabilities.
